Build 10 replaces the earlier builds. It fixes what came up with build 8; for Early Access testers it is the same as build 9. Your favorites and settings are kept.

Please test:
- First connection: before LocSim adds its VPN configuration for the first time, it explains it and asks you to continue (LS-209). You only see this if LocSim's VPN configuration does not exist yet. To see it, delete the configuration in the iOS settings under VPN before you set a location with build 10 for the first time.
- Deleting asks first: removing a favorite with the star, clearing the recent places, turning off Recent Locations, deleting the DDI files, and removing or replacing the pairing file.
- Pairing file: Check Pairing File checks the file more thoroughly. An old lockdown pairing file is reported as the wrong file (LS-102), and a full iPhone as Not enough storage (LS-901).
- Clear: if a Clear does not finish, the Live Activity, the widget and the quick actions keep showing the place, and Clear can be tapped again.
- Questions: when LocSim asks about another VPN or the DDI download, Continue or Download sets the place that asked. Tapping the status line shows the question again.
- Connecting: the status line says when the DDI is being downloaded or installed, and a step that hangs reports its own code instead of LS-204.
- Pasting: more formats, for example "Lng / Lat: 2.35, 48.85", OpenStreetMap directions links and ul.waze.com links.
- Shortcuts: a Set from a Shortcut keeps connecting even if Shortcuts stops waiting.
- Live Activity: while LocSim is open, a Live Activity older than six hours is replaced by a new one before iOS ends it.
- VoiceOver: announcements name the place, and some buttons have larger tap targets.

If something fails, tap the status line, choose Copy Details and send it with your feedback.
