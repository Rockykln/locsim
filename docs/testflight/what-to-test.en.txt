Build 4: more reliable connection, recent locations, pasting coordinates, Shortcuts, a Live Activity and accessibility.

Please test:
- Connection: set a location, leave the app, lock the device, switch to cellular and back. The location should stay simulated until you tap Clear.
- Another VPN: with another VPN selected, Set Location asks before it replaces it.
- Recent locations: the search field shows the last five. Clear removes them; Settings > Map > Recent Locations turns them off.
- Paste: copy coordinates or an Apple Maps or Google Maps link, tap the search field and then Paste.
- Favorites: the star is filled for a saved place; tapping it removes it.
- Live Activity: while a location is active, the Lock Screen shows it with the time it was set and the expanded Dynamic Island with a running timer. Its Clear button ends the simulation. When LocSim was stopped in the background it says "Open LocSim to check the location".
- Shortcuts and Siri: "Set LocSim to <favorite>", "Stop LocSim", and the actions Set Coordinates and Clear Location in the Shortcuts app.
- Pairing: replace the pairing file with the setup script while a location is active. LocSim should close the old connection and check the new file.
- VoiceOver and large text: status changes are announced, buttons are not cut off.

If something fails, tap the status line, choose Copy Details and send it with your feedback.
