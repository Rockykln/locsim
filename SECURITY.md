# Security

Please report security problems privately, not in a public issue:

- GitHub: **Security › Report a vulnerability** in this repository, or
- email: locsim@rockykln.com

Include what you found, how to reproduce it and the LocSim version (Settings › About).
You get an answer within a week.

Pairing files grant access to a device's developer services. Never attach one to a report,
an issue or a pull request.
