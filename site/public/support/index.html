Quick checks

  • LocalDevVPN is connected. The VPN icon appears in the status bar.
  • The device is on Wi-Fi when LocSim connects. Any network works. Internet is only needed when the Developer Disk Image has to be installed.
  • Developer Mode is on under Settings > Privacy & Security.
  • A pairing file is imported under LocSim > Settings > Pairing.
  • LocSim may run in the background: location access While Using the App and LocSim > Settings > Connection > Keep Alive in Background on.

Common questions

The location jumps back to the real one

iOS resets the simulated location when LocSim is closed. Leave the app running in the background, with location access While Using the App and Keep Alive in Background on.

Connecting fails on cellular

Building a connection needs Wi-Fi, any network without internet is enough. Once connected, locations can be changed on cellular. After Clear or closing LocSim, the next connection needs Wi-Fi again.

It stopped working after an iOS update

Pairing files can expire with an update, a reset or after clearing trusted computers. Create a new one, see the setup guide.

Which devices are supported?

iPhone with iOS 17.4 or later.

Do I need a computer?

Once for the setup, and again whenever a new pairing file is needed, for example after an iOS update.

Is any data sent to you?

LocSim itself sends nothing to us. As a TestFlight tester, Apple shares crash reports and feedback with us. Details are in the privacy policy.

How do I remove everything again?

Delete LocSim, delete the pairing file from your computer, and open Settings > Developer > Clear Trusted Computers to revoke the pairing. Optionally remove LocalDevVPN, turn off Developer Mode and turn off Show this iPhone when on Wi-Fi.

Error codes

LocSim shows a code in the status line. Tap the status line to see what to do.

Pairing file

CodeMeaningWhat to do
LS-100No pairing fileImport one under LocSim > Settings > Pairing.
LS-101Pairing file not validCreate a new one, see the setup guide.
LS-102Wrong pairing fileLocSim needs an RPPairing file, not a lockdown pairing file. See the setup guide.

Connection

CodeMeaningWhat to do
LS-200Invalid target addressReset the target IP under Settings > Connection to 10.7.0.1.
LS-201Device not reachableConnect LocalDevVPN.
LS-202Pairing service unavailableCheck LocalDevVPN and Wi-Fi. Allow connections over Wi-Fi: Finder (Mac) or Apple Devices app (Windows), Show this iPhone when on Wi-Fi. Allow Local Network for LocSim under Settings > Privacy & Security > Local Network.
LS-203Pairing rejectedCreate a new pairing file, for example after an iOS update.
LS-204Connection lostCheck LocalDevVPN and Wi-Fi. LocSim reconnects on its own while a location is active.

Developer Disk Image

CodeMeaningWhat to do
LS-300Developer Disk Image not availableCheck that Developer Mode is on.
LS-301Download failedCheck the internet connection.
LS-302Developer Disk Image not installedTry again with an internet connection.

Location

CodeMeaningWhat to do

LS-401Location not setTap Set Location again.

Still stuck? Report a problem

Report a problem

  1. In LocSim, tap the status line below the coordinates and choose Copy Details.
  2. Send an email with what you did, what happened and the copied details. If possible, also add the log from LocSim > Settings > Log.
