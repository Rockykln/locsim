Quick checks

  • The VPN configuration is allowed. Check it under Settings > General > VPN & Device Management. While LocSim is connected, the VPN icon appears in the status bar.
  • The device is on Wi-Fi when LocSim connects. Any network works. Internet is only needed when the Developer Disk Image has to be installed.
  • Developer Mode is on under Settings > Privacy & Security.
  • A pairing file is imported under LocSim > Settings > Pairing.
  • LocSim may run in the background: location access While Using the App and LocSim > Settings > Connection > Keep Alive in Background on.

Error codes

LocSim shows a code in the status line. Tap the status line to see what to do.

Pairing file

CodeMeaningWhat to do
LS-100No pairing fileImport one under LocSim > Settings > Pairing.
LS-101Pairing file not validCreate a new one, see the setup guide.
LS-102Wrong pairing fileLocSim needs an RPPairing file, not a lockdown pairing file. See the setup guide.

Connection

CodeMeaningWhat to do
LS-201Device not reachableJoin a Wi-Fi network.
LS-202Pairing service unavailableJoin a Wi-Fi network. Allow connections over Wi-Fi: Finder (Mac) or Apple Devices app (Windows), Show this iPhone when on Wi-Fi. Allow Local Network for LocSim under Settings > Privacy & Security > Local Network.
LS-203Pairing rejectedCheck that the hostname in LocSim's settings matches the one used by the setup script, or create a new pairing file, for example after an iOS update.
LS-204Connection lostCheck Wi-Fi. LocSim reconnects on its own while a location is active.
LS-205Local connection not startedAllow the VPN configuration when iOS asks.
LS-206Connection failedThe connection broke off. Check Wi-Fi and try again.
LS-207Another VPN is selectedLocSim's local connection replaces it while a location is active. Tap Set Location again, and select your VPN again in Settings afterwards.
LS-208Local Network access offAllow Local Network for LocSim under Settings > Privacy & Security > Local Network.

Developer Disk Image

CodeMeaningWhat to do
LS-300Developer Disk Image not availableCheck that Developer Mode is on.
LS-301Download failedCheck the internet connection.
LS-302Developer Disk Image not installedTry again with an internet connection.
LS-303Developer Disk Image needediOS has not provided it. Tap Download to let LocSim fetch it, about 16 MB.

Location

CodeMeaningWhat to do
LS-400Location service unavailableTurn on LocSim > Settings > Developer Disk Image > Mount Automatically, or restart the device.
LS-401Location not setTap Set Location again.
LS-402Location not clearedQuit LocSim in the App Switcher to restore the real location.

Still stuck? Report a problem

Report a problem

  1. In LocSim, tap the status line below the coordinates and choose Copy Details.
  2. Send an email with what you did, what happened and the copied details. If possible, also add the log from LocSim > Settings > Log.
