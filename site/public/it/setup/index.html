Configurazione

Lo fai una volta sola, con un computer Mac, Windows o Linux e un cavo USB. Dopo, LocSim funziona senza computer.

Prima di iniziare

  • LocSim è installato sul tuo iPhone (iOS 17.4 o versioni successive).
  • Il dispositivo è collegato via USB, sbloccato e ha autorizzato il computer.

1. Attiva Modalità sviluppatore

Apri Impostazioni > Privacy e sicurezza > Modalità sviluppatore, attivala, riavvia e conferma.

L’interruttore compare solo dopo che il dispositivo è stato collegato a Xcode. Senza Xcode, ad esempio su Windows o Linux, puoi farlo comparire con pymobiledevice3:

pymobiledevice3 amfi reveal-developer-mode

2. Consenti connessioni tramite Wi-Fi

Senza questa opzione, il dispositivo non offre l’abbinamento in rete.

  • Mac: seleziona il dispositivo nel Finder e attiva Mostra questo iPhone quando connesso alla rete Wi-Fi.
  • Windows: la stessa opzione nell’app Dispositivi Apple.
  • Linux: pymobiledevice3 lockdown wifi-connections on

3. Crea il file di abbinamento

Lo script scarica idevice-tools, ne verifica il checksum e scrive rppairing.plist. Puoi prima leggere gli script.

Mac e Linux

curl -fLO https://raw.githubusercontent.com/Rockykln/locsim/0ecb6bfc5f9c4978fa2b9d6b29bb725a9f9517f6/tools/make-pairing.sh
bash make-pairing.sh

Su Linux servono anche usbmuxd e glibc 2.38 o successiva: Debian 13, Ubuntu 24.04, Fedora 39 o successive.

Windows

Richiede l’app Dispositivi Apple o iTunes. In PowerShell:

curl.exe -fLO https://raw.githubusercontent.com/Rockykln/locsim/0ecb6bfc5f9c4978fa2b9d6b29bb725a9f9517f6/tools/make-pairing.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File make-pairing.ps1

4. Importa il file in LocSim

  1. Se LocSim è installato, lo script copia il file nell’app e lo elimina dal computer. Apri LocSim: la schermata di configurazione mostra il file come importato.
  2. Altrimenti copia rppairing.plist sul dispositivo con AirDrop, oppure nella cartella di LocSim nel pannello File del Finder o dell’app Dispositivi Apple. Evita i servizi cloud. Poi importalo da LocSim > Impostazioni > Abbinamento ed eliminalo dal computer, perché consente l’accesso al dispositivo.

5. Imposta la tua prima posizione

  1. Connettiti a una rete Wi-Fi qualsiasi e apri LocSim.
  2. Consenti la configurazione VPN e l’accesso alla rete locale quando iOS lo chiede. LocSim usa la configurazione VPN solo per raggiungere questo iPhone.
  3. Tieni premuto sulla mappa, cerca un luogo o inserisci le coordinate, poi tocca “Imposta posizione”.

“Ripristina” riporta la posizione reale.

Cosa devi ripetere

  • Dopo un riavvio: niente, LocSim avvia la connessione quando serve.
  • Dopo un aggiornamento di iOS, un ripristino del dispositivo o la cancellazione dei computer autorizzati: crea un nuovo file di abbinamento (passaggi 3 e 4).

Qualcosa non funziona? Vedi Supporto.
