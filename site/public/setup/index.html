Setup

You do this once, with a Mac, Windows or Linux computer and a USB cable. After that LocSim works without a computer.

Before you start

  • LocSim is installed on your iPhone (iOS 17.4 or later).
  • The device is connected by USB, unlocked and trusts the computer.

1. Enable Developer Mode

Open Settings > Privacy & Security > Developer Mode, turn it on, restart and confirm.

The switch only appears after the device was connected to Xcode. Without Xcode, for example on Windows or Linux, make it appear with pymobiledevice3:

pymobiledevice3 amfi reveal-developer-mode

2. Allow connections over Wi-Fi

Without this the device does not offer pairing on the network.

  • Mac: select the device in Finder and turn on Show this iPhone when on Wi-Fi.
  • Windows: the same option in the Apple Devices app.
  • Linux: pymobiledevice3 lockdown wifi-connections on

3. Create the pairing file

The script downloads idevice-tools, verifies its checksum and writes rppairing.plist. You can read the scripts first.

Mac and Linux

curl -fLO https://raw.githubusercontent.com/Rockykln/locsim/1d43bcb78b9992f57e6fec38ca2d48a3e163b3f0/tools/make-pairing.sh
bash make-pairing.sh

Linux also needs usbmuxd and glibc 2.38 or newer: Debian 13, Ubuntu 24.04, Fedora 39 or later.

Windows

Needs the Apple Devices app or iTunes. In PowerShell:

Invoke-WebRequest -UseBasicParsing -OutFile make-pairing.ps1 https://raw.githubusercontent.com/Rockykln/locsim/1d43bcb78b9992f57e6fec38ca2d48a3e163b3f0/tools/make-pairing.ps1
powershell -ExecutionPolicy Bypass -File make-pairing.ps1

4. Import the file into LocSim

  1. If LocSim is installed, the script copies the file into the app and deletes it from the computer. Open LocSim, and the setup screen shows the file as imported.
  2. Otherwise, copy rppairing.plist to the device with AirDrop, or into the LocSim folder in the Files tab of Finder or the Apple Devices app. Avoid cloud storage. Then import it under LocSim > Settings > Pairing and delete it from the computer, because it grants access to the device.

5. Set your first location

  1. Join any Wi-Fi network and open LocSim.
  2. Allow the VPN configuration and Local Network access when iOS asks. LocSim only uses the VPN configuration to reach this iPhone.
  3. Long-press the map, search for a place or enter coordinates, then tap Set Location.

Clear restores the real location.

What you have to repeat

  • After a restart: nothing to do, LocSim starts its connection when needed.
  • After an iOS update, a device reset or clearing trusted computers: create a new pairing file (steps 3 and 4).
