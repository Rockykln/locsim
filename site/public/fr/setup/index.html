Configuration

À faire une seule fois, avec un ordinateur Mac, Windows ou Linux et un câble USB. Ensuite, LocSim fonctionne sans ordinateur.

Avant de commencer

  • LocSim est installé sur votre iPhone (iOS 17.4 ou version ultérieure).
  • L’appareil est connecté en USB, déverrouillé et fait confiance à l’ordinateur.

1. Activer le mode développeur

Ouvrez Réglages > Confidentialité et sécurité > Mode développeur, activez-le, redémarrez et confirmez.

L’option n’apparaît qu’une fois l’appareil connecté à Xcode. Sans Xcode, par exemple sous Windows ou Linux, faites-la apparaître avec pymobiledevice3 :

pymobiledevice3 amfi reveal-developer-mode

2. Autoriser les connexions en Wi-Fi

Sans ce réglage, l’appareil ne propose pas le jumelage sur le réseau.

  • Mac : sélectionnez l’appareil dans le Finder et activez Afficher cet iPhone en Wi-Fi.
  • Windows : la même option dans l’app Appareils Apple.
  • Linux : pymobiledevice3 lockdown wifi-connections on

3. Créer le fichier de jumelage

Le script télécharge idevice-tools, vérifie sa somme de contrôle et écrit rppairing.plist. Vous pouvez d’abord lire les scripts.

Mac et Linux

curl -fLO https://raw.githubusercontent.com/Rockykln/locsim/00b3b69e4860b184f634867ffe71f2bb13fc2b66/tools/make-pairing.sh
bash make-pairing.sh

Sous Linux, usbmuxd et glibc 2.38 ou plus récent sont également nécessaires : Debian 13, Ubuntu 24.04, Fedora 39 ou ultérieur.

Windows

Nécessite l’app Appareils Apple ou iTunes. Dans PowerShell :

Invoke-WebRequest -UseBasicParsing -OutFile make-pairing.ps1 https://raw.githubusercontent.com/Rockykln/locsim/00b3b69e4860b184f634867ffe71f2bb13fc2b66/tools/make-pairing.ps1
powershell -ExecutionPolicy Bypass -File make-pairing.ps1

4. Importer le fichier dans LocSim

  1. Si LocSim est installé, le script copie le fichier dans l’app et le supprime de l’ordinateur. Ouvrez LocSim : l’écran de configuration indique que le fichier est importé.
  2. Sinon, copiez rppairing.plist sur l’appareil avec AirDrop, ou dans le dossier LocSim de l’onglet Fichiers du Finder ou de l’app Appareils Apple. Évitez le stockage dans le cloud. Importez-le ensuite dans LocSim > Réglages > Jumelage et supprimez-le de l’ordinateur, car il donne accès à l’appareil.

5. Définir votre première position

  1. Rejoignez n’importe quel réseau Wi-Fi et ouvrez LocSim.
  2. Autorisez la configuration VPN et l’accès au réseau local lorsqu’iOS le demande. LocSim utilise la configuration VPN uniquement pour joindre cet iPhone.
  3. Faites un appui prolongé sur la carte, recherchez un lieu ou saisissez des coordonnées, puis touchez « Définir la position ».

« Réinitialiser » rétablit la position réelle.

Ce qu’il faut refaire

  • Après un redémarrage : rien à faire, LocSim établit sa connexion au besoin.
  • Après une mise à jour d’iOS, une réinitialisation de l’appareil ou l’effacement des ordinateurs de confiance : créez un nouveau fichier de jumelage (étapes 3 et 4).

Un problème ? Consultez la page Assistance.
