LocSim: Location Simulator

Set any GPS location on your iPhone, right on the device. Made for developing and testing location-based apps: after a one-time setup there is no Mac, cable or debug session involved.

Request TestFlight inviteSupportSource code

What it does

Same as Xcode

Uses the location simulation service Xcode uses, reached through a loopback VPN on the device.

Pick any place

Long-press the map, search for a place or enter coordinates in decimal or degrees, minutes, seconds.

Stays active

The simulated location holds while you use other apps, as long as LocSim keeps running in the background.

Works on the go

Connect on any Wi-Fi network, then keep changing locations on cellular while LocSim stays connected.

Clear error codes

Every error has a code and a short fix, ready to copy into a support request.

No account, no tracking

No accounts, analytics or tracking. LocSim never sends the pairing file anywhere.

How it works

  1. 1

    Set up once

    Enable Developer Mode and create a pairing file with a Mac, Windows or Linux computer.
    Setup guide

  2. 2

    Connect

    Turn on LocalDevVPN, join any Wi-Fi network and open LocSim.

  3. 3

    Set a location

    Choose a place and tap Set Location. Other apps see it right away.

  4. 4

    Clear

    Tap Clear or close LocSim and the real location returns.

Requirements

  • iPhone with iOS 17.4 or later, Developer Mode enabled
  • LocalDevVPN from the App Store
  • A one-time setup with a Mac, Windows or Linux computer and a USB cable (guide)
  • Wi-Fi whenever LocSim connects, any network. Internet only if the Developer Disk Image has to be installed.

Questions

Is LocSim free?

Yes. LocSim is free and open source under the MIT licence.

Does it need a jailbreak?

No. LocSim uses developer features that iOS provides once Developer Mode is enabled.

Where can I get it?

For now through TestFlight, or by building it yourself with Xcode.

What does the VPN do?

LocalDevVPN only routes traffic for 10.7.0.1 back to the device, so LocSim can reach the device's own developer services. Other traffic is not affected.
