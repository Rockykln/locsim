How it works

  1. 1

    Set up once

    Enable Developer Mode and create a pairing file with a computer. Setup guide

  2. 2

    Connect

    Turn on LocalDevVPN, join any Wi-Fi network and open LocSim.

  3. 3

    Set a location

    Choose a place and tap Set Location. Other apps see it right away.

  4. 4

    Clear

    Tap Clear or close LocSim and the real location returns.

Requirements

  • iPhone with iOS 17.4 or later, Developer Mode enabled
  • LocalDevVPN from the App Store
  • A one-time setup with a Mac, Windows or Linux computer and a USB cable (guide)
  • Wi-Fi whenever LocSim connects, any network. Internet only if the Developer Disk Image has to be installed.

Questions

Is LocSim free?

Yes. LocSim is free and open source under the MIT license.

Does it need a jailbreak?

No. LocSim uses developer features that iOS provides once Developer Mode is enabled.

Where can I get it?

For now through TestFlight, or by building it yourself with Xcode.

What does the VPN do?

LocalDevVPN only routes traffic for 10.7.0.1 back to the device, so LocSim can reach the device's own developer services. Other traffic is not affected.
