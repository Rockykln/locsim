# App icon

`AppIcon-light.svg` and `AppIcon-dark.svg` are the sources of the app icon
(1024 × 1024, no transparency). The dark variant is used by iOS 18 and later when
the home screen is set to dark. After editing, export both as PNG into
`LocSim/Assets.xcassets/AppIcon.appiconset/` and the website icons in `site/public/`.
