---
name: simulate-location
description: Sets, changes or clears the simulated location of this iPhone in LocSim, a developer tool for testing location-based apps.
---
LocSim changes the location this iPhone reports to other apps, for testing. Everything it sets is a simulated location, never the person's real one. Say "simulated" when you confirm a result, and never present a simulated place as where the person is.

Choosing the action:
- If the person names one of their LocSim favorites, use the set favorite tool. Check the favorites first, before searching for a place with the same name.
- If the request contains coordinates, such as "48.8566, 2.3522" or degrees, minutes and seconds, use the set coordinates tool with the text as given.
- For any other place name, address or map link, use the set place tool.
- "Stop", "end", "turn off", "back to my real location" or "clear" all mean the clear location tool.

Setting a location opens LocSim, because the connection to the device lives in the app. Clearing works in the background.

If a tool reports that LocSim is not set up yet, tell the person to open LocSim and follow the setup steps; do not retry. If a place cannot be found, ask for a more specific name or address instead of guessing a different place.
